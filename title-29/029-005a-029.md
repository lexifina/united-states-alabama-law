# Section 29-5A-29 Code Changes to Conform to Chapter 28 of Title 41.
The Code Commissioner shall conform references in the Code of Alabama 1975, to the units, departments, divisions, and other state entities included in Chapter 28, commencing with Section 41-28-1, of Title 41 to reflect the changes required by that chapter. Code changes shall be made at a time determined to be appropriate by the Code Commissioner.
