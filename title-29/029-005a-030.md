# Section 29-5A-30 Code Changes to Conform to Chapter 5A of Title 41.
The Code Commissioner may conform references in the Code of Alabama 1975, to reflect the changes made by Act 2018-129. Code changes, including the renumbering of references to Chapter 5 of Title 41, to reflect the appropriate code sections in Chapter 5A of Title 41, shall be made at a time determined to be appropriate by the Code Commissioner.
