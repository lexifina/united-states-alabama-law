# Section 45-15-170.40 Percolation Tests.
(a) In Cleburne County, any law, rule, or regulation to the contrary notwithstanding, upon the request of any property owner, the county health officer may allow the percolation tests for septic tank installation to be satisfied by using pertinent soil maps, and other such data in the files of the county health department.
(b) A fifty dollar ($50) fee shall be charged for the performance of percolation tests, whether by file data or otherwise.
